# OKX NT Community

An independent source fork of [NautilusTrader](https://github.com/nautechsystems/nautilus_trader),
maintained by [silarin](https://github.com/silarin). The changes maintained here focus on native OKX
fill recovery, exact fee accounting, and strategy order cleanup during managed exit.

Independently maintained by silarin. Neither Nautech Systems Pty Ltd nor the official NautilusTrader
project is affiliated with this repository, endorses it, or provides support for it.

## Support

Report issues with this fork through [this repository's issues](https://github.com/silarin/okx-nt-community/issues).
Upstream documentation and community channels describe the original NautilusTrader project.

## Source and attribution

This repository preserves the upstream source history and its copyright notices. Crate and module
identifiers retain their upstream names for source compatibility.

Clone this fork:

```bash
git clone --branch develop https://github.com/silarin/okx-nt-community.git
cd okx-nt-community
```

Follow the platform prerequisites in the inherited
[environment setup guide](docs/developer_guide/environment_setup.md), then continue with its tool
installation and build commands in this checkout. Use the clone commands above in place of the
upstream clone and directory-change commands in that guide.

For the original project, see the [upstream repository](https://github.com/nautechsystems/nautilus_trader).
